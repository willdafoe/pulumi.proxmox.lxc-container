# Pulumi Proxmox LXC (Python)

Manage LXC containers on a Proxmox VE host using Pulumi and Python.

## 🚀 Features

- Create/Delete LXC containers
- Start/Stop containers
- Query container status
- List available LXC templates

## 📦 Requirements

- Proxmox VE host with API access
- Python 3.8+
- Pulumi CLI

## 🔐 Pulumi Config Setup

```bash
pulumi config set proxmox:host 10.1.0.148
pulumi config set proxmox:user ralph@pve
pulumi config set proxmox:token_id pulumi-cli
pulumi config set --secret proxmox:token_secret your-token-secret
pulumi config set proxmox:node hades
```

🛠 Usage
```bash
make install
make up
```
🧹 Clean Up
```bash
make destroy
```

📁 Structure

lxc_container.py: Pulumi dynamic resource
proxmox_api.py: API wrapper with token-based auth
__main__.py: Your resource definitions
